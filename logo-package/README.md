# Logo Package

Circular logo with transparent background outside the green ring. All artwork inside the circle (including white details) is preserved.

## Folders

- `web/` - Drop-in files for your site root (favicon.ico, PNG favicons, Apple touch icons, Android/PWA icons, mstile, logo.png, site.webmanifest)
- `png/` - All sizes as PNG (16 to 2048 px)
- `favicon.ico` - Multi-size favicon at root
- `logo-master-2048.png` - High-resolution master

## Sizes included
16, 32, 48, 64, 96, 120, 128, 144, 152, 167, 180, 192, 256, 384, 512, 1024, 2048

## HTML <head> snippet

```html
<link rel="icon" type="image/x-icon" href="/favicon.ico">
<link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png">
<link rel="icon" type="image/png" sizes="16x16" href="/favicon-16x16.png">
<link rel="apple-touch-icon" sizes="180x180" href="/apple-touch-icon-180x180.png">
<link rel="manifest" href="/site.webmanifest">
<meta name="theme-color" content="#16a34a">
```
